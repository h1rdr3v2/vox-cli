# Security

Please report security issues privately through GitHub's [private vulnerability reporting](https://github.com/h1rdr3v2/vox-cli/security/advisories/new), not in a public issue.

Fixes go into the latest release only.

vox runs entirely on your computer. Its server listens only on 127.0.0.1, sends no telemetry, and touches the network only to download models you ask for.
